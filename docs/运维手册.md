# 线上运维手册（agentdesk.2007116.xyz）

> 给「评审期间服务挂了怎么救」用。整套东西只有三个进程：`agentdesk.service`（FastAPI）、
> `cloudflared.service`（隧道）、系统自带服务。数据是一个 SQLite 文件，没有外部依赖。

## 一、拓扑

```
评审浏览器
   │ https://agentdesk.2007116.xyz
   ▼
Cloudflare 边缘（自动证书）
   │ 隧道 my-tunnel（beb307aa-bcad-4611-a525-87eb01c9b29f）
   ▼
cloudflared.service  ──► http://localhost:8000  ──► agentdesk.service（uvicorn，2 worker）
                                                        └─ /opt/agentdesk/data/agentdesk.db
```

服务器：`my416`，Ubuntu 24.04，Tailscale 内网 `100.96.130.44`（SSH 只走 tailnet）。

## 二、三条救命命令

```bash
# 1. 服务是不是活的
curl -s http://127.0.0.1:8000/api/health
systemctl is-active agentdesk cloudflared

# 2. 重启（99% 的问题这一条解决）
sudo systemctl restart agentdesk

# 3. 看日志
sudo journalctl -u agentdesk -n 50 --no-pager
sudo journalctl -u cloudflared -n 50 --no-pager
```

## 三、公网打不开时的排查顺序

| 现象 | 检查 | 处理 |
|---|---|---|
| `curl https://agentdesk.2007116.xyz/api/health` 超时 | `systemctl is-active cloudflared` | `sudo systemctl restart cloudflared` |
| 502 / 1033 错误 | 本机 `curl 127.0.0.1:8000/api/health` | 不行就 `restart agentdesk` |
| 本机 200、公网 502 | `/etc/cloudflared/config.yml` 里 `agentdesk` 那条 `service` 是否 `http://localhost:8000` | 改回后 restart cloudflared |
| 登录后立刻被踢回 `/login` | `SECRET_KEY` 变了（重启时被重写） | 重新登录即可；`/etc/systemd/system/agentdesk.service` 里的值不要手改 |
| 页面白屏、控制台 404 | `ls /opt/agentdesk/apps/web/dist` | 缺文件时重新解压前端产物（见下） |
| 模型报 401/超时 | `curl -o /dev/null -w '%{http_code}' https://api.deepseek.com` | 401 属正常（无鉴权头）；超时说明出口网络问题 |

## 四、常用维护

```bash
# 代码更新（GitHub 直连不通时走本机代理）
cd /opt/agentdesk
sudo HTTPS_PROXY=http://127.0.0.1:7897 git pull
sudo systemctl restart agentdesk

# 重建演示数据（回到 3 场会议 / 16 条任务）
sudo PYTHONPATH=/opt/agentdesk/apps/api /opt/agentdesk/.venv/bin/python /opt/agentdesk/apps/api/seed/demo.py --force
sudo systemctl restart agentdesk

# 前端换产物（本地 pnpm build 后）
scp apps/web/dist/assets/* txrnb666@100.96.130.44:/tmp/assets/
sudo cp -r /tmp/assets/* /opt/agentdesk/apps/web/dist/assets/
```

## 五、关键文件

| 路径 | 作用 |
|---|---|
| `/etc/systemd/system/agentdesk.service` | 后端服务定义（含 LLM key、SECRET_KEY、CORS） |
| `/etc/cloudflared/config.yml` | 隧道 ingress：`agentdesk.2007116.xyz → localhost:8000` |
| `/opt/agentdesk/data/agentdesk.db` | 全部业务数据（SQLite，可直接备份） |
| `/opt/agentdesk/apps/web/dist/` | 前端静态产物 |
| `/opt/agentdesk/deploy/` | 部署脚本与文档 |
