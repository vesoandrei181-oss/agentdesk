# 智协台 AgentDesk · 演示视频逐字稿（6 分 40 秒）

> 用途：录屏旁白。每段前面的时间是累计时间点，方便剪片对齐。
> 语速按每分钟 200 字左右设计，全程普通话，字幕由脚本自动生成。

---

## 00:00 — 00:40　问题

开完会之后的事，往往比开会更耗人。

一场一小时的评审会，散会后要有一个人回听录音、整理纪要、把结论摘出来、把待办派下去，再在周报里复述一遍。这个人通常是团队里最忙的那一个，每次要花四十多分钟。更麻烦的是三个副作用：结论被"顺"得走了样，"先看看"变成"已决定"；待办落到文档里只剩一句"跟进相关工作"，没有责任人；三个月后新人问"我们当时的阈值是怎么定的"，没人答得上来。

市面上的 AI 会议工具大多解决了把话变成字，但没解决这些字能不能被信任。

这是智协台 AgentDesk 想做的事：让 AI 的每一句输出，都能点回到原始证据。

## 00:40 — 01:25　工作台

这是登录后的工作台。左边是六个工作区模块，右边是这周的整体情况：累计会议、沉淀决议、证据覆盖率、节省的整理工时。下面这张曲线是最近十四天的分析任务量，右边是八个 Agent 的调用分布。

左下角这个徽标显示当前接的模型服务，绿色代表在线。

请注意这里的一个细节：所有数字都来自真实运行记录，不是写死的假数据。往下每一个页面都是这样。

## 01:25 — 02:10　会议纪要列表与新建

进入会议纪要。这些是演示数据，三场会，二十六段转写。

新建一场会只要两步：贴上带时间戳的转写，或者直接贴对话文本。左边这块是实时解析预览，它会识别时间戳和说话人前缀，确认后写库并触发分析。

分析走后台任务，页面每两秒多轮询一次状态，用户不用干等。一场十二段的会，现在大概三十秒出结果。

## 02:10 — 03:05　证据链（核心）

打开第一场会。上面这排是统计：五条决议、四条待办、证据覆盖四比五、成本一分二。

重点看第二个页签，证据链。每一条决议下面都挂着原始引文、说话人、时间点，右边是置信度。比如这条"9 月 10 日前交付可对外演示的版本"，引文来自孟嘉祺在 1 分 12 秒说的原话，系统比对下来重合度 94%，标为有据。

下面这条是未决问题，它没有引文。这是故意的：系统在落库前会用字符串相似度把引文回查到转写原文，重合度低于 0.55 的条目直接丢弃，丢弃后如果没剩下证据，这条就不会被写成决议，而是降级成"未决"，提示需要人来确认。

我们认为这才是可信 AI 的样子：不是让模型更会编，而是让它编不出来的时候敢承认。

## 03:05 — 03:40　Agent Trace

第四个页签是执行链。六个 Agent 依次做了什么、输入输出摘要、token 数、耗时，全在这里。右边是运行汇总和质量指标。

这一页不只是给评委看的。调优的时候，我们就是靠它发现"复核 Agent 花了十二秒"这种问题的。

## 03:40 — 04:40　智能写作（Diff）

进入智能写作。左侧是文档，右侧是一句话指令。

这里有一个刻意的设计：我们不让模型重写整篇文档。提示词明确要求它输出补丁——改哪一句、改成什么、为什么改。后端拿到补丁后在原文里定位并应用，再算出逐行的差异。

按一下生成。七八秒后，右边出现文本体检：平均句长、最长句、套话数量、规则问题。下面是模型给的修改建议，每条都带理由，比如"把『接入』改成『换成』更口语"。再往下是差异确认，每一块都可以单独取消勾选。

这样用户接受的是"这几处改动"，不是"整篇被换掉"。办公文档里大部分句子本来是对的，整篇重写会把对的改坏，人也不敢保存。

实测四条常用指令，补丁定位成功率百分之百。

## 04:40 — 05:35　知识库问答

知识库。上传的资料会被切成五百二十字一段、重叠八十，同时建 BM25 索引和向量索引。

问一个具体问题。注意它不是等七秒才出结果：先推一次检索事件，把召回的片段先显示出来，再逐 token 输出正文。

回答里每个 [1] [2] 都能点开看原文。引用卡片上标着强支撑、弱支撑——强支撑说明这句话确实来自该片段，弱支撑提示"这句可能是模型自己的总结，你要自己回查"。

这个标注比"显示来源"更有用，因为它告诉你能不能直接引用。

## 05:35 — 06:05　任务看板与周报

任务看板，四列状态。卡片上的进度条不是普通进度，是 P50 和 P90：大概率三天干完，但拖到五天的可能性也不小。描述里如果出现"调研""梳理"这类模糊动词，区间会自动拉宽——这类任务本来就不该给一个确定数字。

周报页做成两段：左边的数据面板本地聚合，秒出；右边正文点一下才生成，数据没变就不重复花钱。

## 06:05 — 06:40　成本、部署与结尾

最后看运行观测和设置。累计三十三次运行、十一万 token、七分六美分，缓存命中二十六次。

设置里可以切四档模型路由。默认这档全部走快模型并关闭思维链——这是实测出来的结论：同一个抽取任务，快模型抽得比大模型更多、快十倍；大模型开着思维链在四千 token 预算内一条都产不出来，因为它把预算全花在思考上了。

这个项目真正花时间的不是页面，是这些看不见的东西：让输出可校验，让失败能降级，让成本看得见。
