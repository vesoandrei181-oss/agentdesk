```
apps/api/app/core/     编排核 12 个模块（providers / pipeline / structured / rag / writer / predict / routing / cache / guard / trace / embedding / prompts）

apps/web/src/          12 个页面、9 个组件、4 个 lib 模块
apps/api/seed/demo.py  演示数据：3 场会议 / 26 段转写 / 11 条决议 / 10 条待办 / 16 条任务 / 3 份资料 / 14 天运行记录
```

本地跑起来：

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r apps/api/requirements.txt
$env:PYTHONPATH="apps/api"; python apps/api/seed/demo.py
$env:PYTHONPATH="apps/api"; uvicorn app.main:app --port 8000
# 浏览器打开 http://127.0.0.1:8000 ，demo@agentdesk.dev / Demo@2026
```

## 五、还需要你做的事

1. **撤销那个 GitHub token**：仓库已推送完成，token 不再需要。到 https://github.com/settings/tokens 找到 `agentdesk-upload` 点 `Delete`。之后如果还要推代码，用你自己账号的凭据即可（remote 已经是干净地址，不含 token）。
2. **（可选）固定域名**：现在用的是 Cloudflare 快速隧道，地址随机、进程停止即失效。你有域名的话，配成命名隧道后地址固定成 `demo.你的域名.com`，需要 Cloudflare API Token 或本机执行一次 `cloudflared tunnel login`。
3. **评审期间保活**：演示地址依赖本机进程常驻，可以用 `scripts/run_demo.ps1` 一键起后端 + 隧道；评审结束前别关机。
